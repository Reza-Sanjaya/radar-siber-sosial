# Teks untuk formulir pendaftaran / submission

**Nama karya:** Radar Siber Sosial
**Kategori:** Siber Sosial

**Deskripsi singkat (siap salin):**
Radar Siber Sosial adalah dasbor deteksi dini untuk ruang siber sosial. Aplikasi menganalisis unggahan (CSV/XLSX) untuk mendeteksi disinformasi, provokasi, ajakan kekerasan, penipuan yang mencatut institusi (mis. rekrutmen palsu), dan pembocoran data pribadi, lalu membedakan tren organik dari kampanye terkoordinasi. Hasilnya berupa Indeks Siber Sosial (AMAN/WASPADA/SIAGA/AWAS), peringatan beralasan, rekomendasi tindakan, draf klarifikasi, dan laporan SITREP. Seluruh skor dapat dijelaskan dan ditelusuri ke isyarat penyebabnya; aplikasi berjalan offline, mengaliaskan akun, menyamarkan data pribadi, dan tidak mengambil tindakan otomatis (human-in-the-loop). Dibangun dengan Python dan Streamlit.

**Teknologi:** Python, Streamlit, pandas, NumPy, Plotly, openpyxl (open source, diatribusi). Pengembangan dibantu asisten AI (Claude).
